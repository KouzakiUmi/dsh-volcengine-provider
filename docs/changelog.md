## 0.2.2

- 登录后展示官方身份与独立本地备注；旧 OAuth 账号可只读补齐身份摘要。
- 空账号直接网页登录，已有账号可登录其他身份；登录后提供明确的套餐选用与启用入口。
- 每次 OAuth 使用独立凭据目录，失败或取消不覆盖原身份；真实授权仍由官方 CLI 在系统默认浏览器完成。
- 修复登录进度通信失败导致无法取消、启动响应丢失和设置冲突后的恢复；删除账号同步关闭旧编辑草稿。
- 额度查询不再锁住账号管理，账号切换隔离迟到响应；强制刷新失败不复用旧成功数据。
- 修复模型参数继承目录默认的逻辑，明确恢复默认会重新启用停用模型；路由失败区分保存配置与实际生效状态。
- 缺少套餐绑定或目录访问条件时说明原因；高级技术信息折叠，改进空状态、额度分组及窄屏可读性。
- 状态保存增加跨实例文件锁与磁盘 revision 校验，避免多个进程覆盖账号配置。

验证：240 项 JavaScript 测试、7 项归档测试及离线浏览器完整路径通过。真实 OAuth、在线推理及生产安装的验收边界见[验证记录](validation.md)。

## 0.2.1

- 修复前端工厂导出协议不兼容导致 DSH 启动失败的问题。
- 测试与浏览器验证使用宿主真实的单参数加载方式；构建在测试之前执行，构建产物验证不再跳过。
- 损坏的模型目录行显示为缓存错误，设置页仍可打开并刷新修复。
- 取消登录会中止尚未提交的账号绑定写入，并清理临时文件。

## 0.2.0

- 插件显示名、设置页与文档标题采用「火山方舟 Provider」，保留技术包名 `dsh-volcengine-provider` 和内部标识。
- 新增独立套餐开关、逐模型开关与参数编辑；配置按账号、套餐、模型保存，可恢复默认。

- 旧状态兼容迁移为版本 2；关闭套餐保留账号选择，刷新目录保留模型配置。
- 已准备的请求持有旧配置和适配器上下文，设置更新不会造成凭据上下文提前释放。

## 0.1.0 · 开发预览

### 插件

- 分离国内个人 Agent Plan / Coding Plan 两条模型路由。
- 账号元数据与宿主凭据引用管理；两套订阅独立选择账号。
- 官方 ArkCli `volc-sso` 网页登录、账号隔离目录、进度/取消/超时与登录结果核验。
- 官方套餐模型目录拉取，优先使用 `output_name`；目录按账号与订阅隔离。
- IAM AK/SK 与 OAuth 两种额度查询路径；Coding 百分比与 Agent AFP 能力分组。
- 原子路由更新、失败保留旧路由、损坏缓存可诊断与恢复。
- OAuth 推理 Key 短时内存缓存、并发共享与生命周期失效。

### 工程与文档

- GitHub README 主页、真实组件假数据预览、使用及接口文档。
- Node 22.19.0 / 24、Ubuntu / Windows CI 配置。
- 插件包与 SHA-256 artifact；版本标签触发 npm Trusted Publishing 和 GitHub Release。
- 技术包名为 `dsh-volcengine-provider`，采用 MIT 许可。

### 验证边界

已通过隔离测试、实际目标 Core 加载和离线 React/Chrome 交互验证。真实 ArkCli OAuth 首登、在线接口、推理调用与生产安装待验收。具体结果见[验证记录](validation.md)。
