# 更新记录

## 0.2.6

- 精简设置页：账号管理按需展开，双套餐随页面宽度并列或堆叠，额度优先展示，模型技术参数按需查看。
- 额度窗口在接口提供有效重置时间时显示实时倒计时；时间缺失、无效或已到期时明确提示，不猜测额度重置结果。
- 改进深浅色状态提示、下拉选项和输入占位文字的可读性，保留账号、套餐及模型操作。

## 0.2.5

- 按官方文档补齐当前固定模型的思考档位、默认值和开关，默认值不再统一选择 low；未公开的控制项与动态路由分别标注。
- 复用公开 Core/SDK 接口进行模型级 Messages 适配，区分 enabled+effort 与 V4.1 的 adaptive+effort；显式关闭和服务端默认分别处理。
- 保留旧参数覆盖与预算兼容设置，对失效继承档位和常驻思考的旧关闭配置提供修复提示。

## 0.2.4

- 固化当前两套套餐的官方模型参数与显式别名，补齐 Mini、Kimi K3.1、V4 Pro/Flash、Kimi K2.7 与 MiniMax M3，纠正旧 32K 回退及输出整数；逐字段来源与冲突见[能力参数](model-capabilities.md)。
- 旧缓存读取时合并新快照默认值，保留账号、模型调用 ID、启用状态及用户覆盖；未知版本与 Auto 不猜上限。
- 设置页统一账号/双套餐分区、按钮层级、主题令牌、紧凑状态、技术信息折叠及 390px 布局。
- 补齐友好模型名称，旧代码式名称在读取时更新；调用 ID 收入技术详情，推理和配置键保持原 ID。
- 兼容旧 GLM medium 默认档位：保存值保留，失效档位暂不强制调用，页面提示重新选择。

## 0.2.3

- 网页登录使用官方方舟 ArkCli 同设备授权页与自动回调；CLI 私有启动桥将链接原样转交 Playwright 独立临时 Chrome，不再让隔离环境启动日常浏览器。
- 独立驱动隔离调试日志，结束、取消及超时回收所属窗口和 IPC；不读取网页、密码、Cookie 或授权码，不修改系统默认浏览器或日常 Chrome 配置。
- 当前网页登录限定已核验的 Windows ArkCli 1.0.37，其他版本/平台在启动前拒绝；通用归档包含 Windows 原生桥，POSIX opener 固定执行权限。
- 已通过真实同设备登录、自动回调、官方身份与两套个人套餐核验、临时绑定和清理；生产安装、真实额度和推理不在本次验收范围。

## 0.2.2

- 登录后展示官方身份与独立本地备注；旧 OAuth 账号可只读补齐身份摘要。
- 空账号直接网页登录，已有账号可登录其他身份；登录后提供明确的套餐选用与启用入口。
- 每次 OAuth 使用独立凭据目录，失败或取消不覆盖原身份；真实授权仍由官方 CLI 在系统默认浏览器完成。
- 修复登录进度通信失败导致无法取消、启动响应丢失和设置冲突后的恢复；删除账号同步关闭旧编辑草稿。
- 额度查询不再锁住账号管理，账号切换隔离迟到响应；强制刷新失败不复用旧成功数据。
- 修复模型参数继承目录默认的逻辑，明确恢复默认会重新启用停用模型；路由失败区分保存配置与实际生效状态。
- 缺少套餐绑定或目录访问条件时说明原因；高级技术信息折叠，改进空状态、额度分组及窄屏可读性。
- 状态保存增加跨实例文件锁与磁盘 revision 校验，避免多个进程覆盖账号配置。

验证：240 项 JavaScript 测试、7 项归档测试及离线浏览器完整路径通过。真实 OAuth、在线推理及生产安装的验收边界见[验证记录](validation.md)。

## 0.1.0 · 开发预览

- 分离国内个人 Agent Plan / Coding Plan 两条模型路由。
- 账号元数据与宿主凭据引用管理；两套订阅独立选择账号。
